Lista de ConvÃªnios

Esta consulta retorna uma lista de convênios entre um concedente e um beneficiado e seus respectivos valores de total partida, total contrapartida e total do convênio.

 

URL

/convenio/json-convenios-entidades-detalhes/<id_concedente>/<id_beneficiado>

 

MÉTODO

GET

 

PARÂMETROS

Obrigatórios

Nome Tipo Descrição
limit integer Seta um limite de resultados apresentados na consulta.
offset integer Seta a quantidade de valores que será ignorada no início dos resultados. Apresenta o próximo valor após o offset.
data_inicio_dti_ Date Seta a data inicial que será realizada a consulta. (dd/mm/yyyy)
data_inicio_dtf_ Date Seta a data final que será realizada a consulta. (dd/mm/yyyy)
id_concedente integer Define por qual concedente a consulta será filtrada.
id_beneficiado integer Define or qual beneficiado a consulta será filtrada.

 

Opcionais

Nome Tipo Descrição
descricao_convenio text Filtra pela descrição do convênio entre os retornados na consulta.
sort text Define o campo o qual será ordenada a consulta.
order text Define a ordem que será ordenada a consulta. Valores: asc / desc

 

NOTAS

Todos os serviços devem ser consultados utilizando requisições AJAX. Para tanto, deve-se configurar o cabeçalho X-Requested-With para XMLHttpRequest.

 

EXEMPLO

URL utilizada: http://transparencia.al.gov.br/convenio/json-convenios-entidades-detalhes/410504/540034/?data_inicio_dti_=01/01/2015&data_inicio_dtf_=31/12/2015&limit=2&offset=0
